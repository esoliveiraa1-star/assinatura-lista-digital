# Assinatura lista digital

Você sobe o PDF da lista, o painel gera um link e o contratante confere e assina no celular. O PDF assinado vai para o seu Google Drive.

- `apps-script/` : serviço do Google (Code.gs e appsscript.json). Vai para script.google.com.
- `site/` : index.html (painel), assinar.html (página do contratante) e config.js. Vai para o repositório do GitHub (GitHub Pages).

Passo a passo completo no tutorial em PDF.
